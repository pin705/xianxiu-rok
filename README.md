# Sơn Hà Tiên Tông

Game tu tiên chiến lược (SLG) chạy trên trình duyệt: dựng tông môn, thu nhận trưởng lão, xuất quân đánh yêu thú, độ kiếp, luân hồi. Offline, lưu trên máy, cài được như app (PWA). Tiếng Việt + English.

```bash
npm install
npm run dev      # chơi thử: http://localhost:5173
npm test         # test luật game
npm run check    # kiểm tra kiểu
npm run sim      # bot chơi 30 ngày ảo, in nhịp tiến độ
npm run build    # bản tĩnh ở client/dist
```

- [PLAN.md](PLAN.md) — tầm nhìn, hệ thống, kỹ thuật, lộ trình, cách phát hành (mục 13).
- [UX.md](UX.md) — luồng màn hình, hệ thiết kế.
